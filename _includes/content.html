{%- comment -%} The page body, with the relative image paths of a translated page pointed at the site root. A translation lives in its language directory, and its Markdown is Weblate's copy of the English page, image paths included: `images/form.png` in fr/index.md resolves to /fr/images/form.png, which does not exist. The screenshots are shared by every language, so the path is resolved from the root instead — no copy of `images/` per language. On an English page jekyll-relative-links has already made the path absolute, and nothing needs doing.
